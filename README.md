# 桃源智助 —— AI 校园与社区便民服务平台

> “智创便民”AI 辅助网页与软件设计比赛参赛作品 · 演示原型 v1.0.0
> 面向 **机电工程学院学生**（校园场景）与 **桃二社区居民**（社区场景）

---

## 一、这个项目是什么

一个**纯前端、可离线、双击即用**的便民服务网页。它把分散的校园与社区服务信息集中到一个入口，并用**本地知识库驱动的 AI 助手**把“看不懂的办事流程”翻译成“照着做的步骤”。

一句话卖点：**一个入口、一句提问、一份步骤、一张清单。**

**重要说明（先看这一条）**：站内所有服务信息、通知公告与问答内容**都是比赛用的模拟演示数据**，不代表任何学校或社区的真实政策。平台**没有**接入在线大模型，AI 助手使用的是本地知识库 + 规则匹配。这些说明在页面多处都做了标注，作品中不作任何夸大。

## 三、怎么运行（零基础版）

### 方法一：双击打开（最简单，推荐）

1. 打开文件夹 `taoyuan-zhizhu`；
2. **双击 `index.html`**；
3. 浏览器会自动打开，稍等约 0.3 秒的加载动画，就能看到首页了。

> 如果双击后是用记事本打开的：右键 `index.html` → **打开方式** → 选择 **Microsoft Edge** 或 **Google Chrome**。

### 方法二：拖进浏览器

打开浏览器（Edge / Chrome），把 `index.html` 直接**拖进浏览器窗口**即可。

### 方法三：本地服务器（可选，只在需要分享给同一局域网的人时使用）

如果电脑上装了 Python，在项目文件夹里打开命令行执行：

```
python -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`。

### 手机上看效果

- 把 `index.html` 通过微信/QQ 发到手机，用手机浏览器打开；
- 或者在电脑浏览器里按 `F12` → 点击左上角的手机图标（设备模拟），选择 iPhone / Android 机型查看。
- 手机端会自动切换为底部导航栏布局。

### 需要注意的两点

1. **换浏览器 = 换数据**。收藏、待办、对话记录保存在“浏览器自己的存储”里，用 Edge 打开产生的数据，用 Chrome 打开是看不到的，这是正常的。
2. **无痕模式 / 清除浏览器数据**会清空这些记录。想留存，用「我的便民清单 → 导出备份」保存成 JSON 文件。

| 想做什么 | 搜索这个关键词 | 说明 |

| 增加一项校园服务 | `const CAMPUS_SERVICES = [` | 复制一整条 `{ id: 'xxx', ... }`，改 id（不能重复）、名称、步骤等 |

## 八、常见问题（FAQ）

**1. 双击后页面空白 / 只有加载动画？**
先按 `F5` 刷新。若仍空白，按 `F12` 看 Console 里的红色报错；也确认浏览器没有禁用 JavaScript（设置 → 隐私和安全性 → 网站权限）。

**2. 样式全乱了？**
说明文件被改坏了（多半是少了一个 `}`）。用备份重新替换 `index.html`，或运行 `node dev-tools/check.mjs index.html` 定位问题。

**3. 收藏和待办刷新后不见了？**
检查是否用了**无痕/隐私模式**，或浏览器设置了“关闭时清除 Cookie 和网站数据”。用普通窗口打开即可。

**4. 想接入真正的大模型（ChatGPT / 通义 / DeepSeek 等）怎么办？**
三步，且**前端永远不放密钥**：
1. 自己写一个最简后端（Node / Python 都行），由它保存 API Key 并转发请求；
2. 在 `index.html` 的 `CONFIG` 里把 `aiMode` 改成 `'remote'`，`remoteEndpoint` 填你的后端地址；
3. 代码里已经写好调用与失败回退逻辑（`callRemoteModel`）：接口调不通会自动回退到本地知识库，并在回答里注明原因。
> 注意：`file://` 直接打开时浏览器会拦截跨域请求，接入远程接口需要按第三节的“方法三”用本地服务器打开。

**5. 可以把数据存到服务器 / 做成小程序吗？**
可以，属于第八节的后续规划：需要后端与学校、社区的正式授权，本版本不涉及。

## 九、答辩演示动线（建议 3 分钟）

1. **开场（20 秒）**：打开首页，念一句话定位——“把分散的便民信息，变成一句提问和一份步骤。”
2. **痛点（20 秒）**：指首页三行要点：信息分散、流程不清、生活服务难找。
3. **AI 助手（60 秒，重点）**：在首屏输入框输入「校园卡丢了怎么办」→ 自动跳转并给出结构化步骤 → 紧接着输入「需要什么材料」演示**多轮追问** → 再输入「今天天气怎么样」演示**未收录兜底**，强调“不知道就说不知道，绝不编造政策”。
4. **服务与搜索（30 秒）**：打开校园卡挂失详情页，指出步骤 / 材料 / 地点时间费用；再用搜索「居住证明」展示跨类型结果与高亮。

6. **收尾（20 秒）**：打开「关于我们」，指真实性对照表与后续规划，说明“哪些已完成、哪些是模拟数据、下一步怎么走”，主动交代边界反而更可信。
